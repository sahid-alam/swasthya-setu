# Repo Hygiene

- Commit messages: conventional format `feat|fix|chore(scope): message`.
  No "Co-Authored-By", no "Generated with", no AI attribution lines ever.
- Never stage: .env, .venv/, node_modules/, __pycache__/, *.pyc, ml/artifacts
  regenerated by hand. Check `git status` before every commit.
- Secrets: if a diff contains anything shaped like a key/token, stop and flag
  in chat instead of committing.
- Branches: demo-critical work on main only when /demo-check passes. Risky or
  experimental work on feature branches.
- Never: force-push, reset --hard, rewrite pushed history.
- Before push: run make lint + make test; both green or say why not.
